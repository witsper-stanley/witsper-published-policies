## §1 採購治理

### §1.1 採購職責分工

電腦設備採購由 **TO 小隊(總務)統一執行**,各部門不自行採購。

TO 小隊負責兩種採購情境:

**(a) 庫存補充採購**:TO 小隊依本原則定期盤點電腦庫存,當備用機低於 §1.3 規定之最低數量時主動發起採購,不必等候個別需求。

**(b) 個別配置採購**:用人部門主管於下列情境填《電腦設備申請單》送交 TO 小隊,TO 小隊收件後判斷可從備用機配發或啟動新採購:

- 新進夥伴報到前
- 在職夥伴申請換機
- 在職夥伴申請增設設備

**《電腦設備申請單》欄位皆需完整填寫**:

- 使用人姓名
- 所屬部門
- 申請原因(新進報到 / 換機 / 增設,擇一並填寫說明)
- 作業系統需求(macOS / Windows,擇一)
- 預計報到日或需求日期

### §1.2 採購簽核層級

電腦設備採購案件依「是否照 §4.4 標準採購清單」與「金額」適用以下簽核鏈:

| 採購情境 | 簽核路徑 |
|---|---|
| 照《標準採購清單》採購 | 總務 → TO 小隊主管 → FO 小隊 |
| 偏離《標準採購清單》採購 | 總務 → TO 小隊主管 → **IT 小隊主管** → FO 小隊 |
| 單次採購 ≥ NT$100,000 | 上述路徑後加 CFO → CEO |

採購簽呈內 TO 小隊標明「採購類型」(照清單 / 偏離清單),決定走哪條路徑。

**設計理由**:《標準採購清單》由 TO 小隊維護(§4.4),規格把關集中於事前;事後 IT 小隊僅在偏離清單之例外採購介入,不每筆過簽,避免重複動作。

「**單次採購**」定義:同一採購申請單所含所有品項的合計金額。分批申請以規避 NT$100,000 門檻者,各批次合計視為同一次採購,適用十萬以上簽核路徑。

### §1.3 備用機儲備要求

TO 小隊維持以下備用機庫存規定。儲備不足時,優先列入下一採購週期補齊:

| 設備等級 | 庫存規定 | 補充觸發 |
|---|---|---|
| 高規格筆電(≥ NT$40,000) | 不留庫存 | 有需求時走採購;臨時需求可由一般規格備用機銜接 |
| 一般規格筆電(< NT$40,000) | 3 台 | 低於 3 台時,下一採購週期補齊 |
| 其他(桌機、特規設備) | 依需求評估 | 由 TO 小隊與 IT 小隊共同評估 |

備用機**不長期占用個人**,用途為縮短新進夥伴等候時間與故障緊急替換。

## §2 設備配置資格

### §2.1 設備類型預設原則

WitsPer 以**筆電作為全公司標準配置**。下列情況例外配置桌機:

- 業務性質完全在固定工位作業、無移動辦公需求,且高規格運算需求以桌機更佳(例:VU 小隊算圖、FO 小隊大型資料處理)
- 部門主管基於工作需求提出說明,經 IT 小隊主管核准

主管及以上職級之夥伴,以及有外勤、拜訪客戶、出差等移動辦公需求之夥伴,**配置筆電**。

### §2.2 高規格設備配置資格

下列部門夥伴在工作需求確認後,得申請高規格配置(規格標準見 §4.3):

| 部門 | 高規格使用情境 |
|---|---|
| VU 小隊(視覺製作) | 影像剪輯、動態設計、3D 算圖等高 GPU 需求 |
| IT 小隊(資訊技術) | 系統開發、虛擬化環境、多容器同時運行 |

其他部門(含 FO 小隊)如有高規格需求(例:大型資料 Power BI、超大財務模型),由部門主管提出說明,**IT 小隊主管**核准。

### §2.3 多設備持有規定

一位夥伴同時持有兩台(含)以上電腦設備(無論筆電或桌機)即屬多設備持有,於《電腦設備申請單》勾選「增設設備(多設備持有)」,經 **IT 小隊主管核准**後配發。

多設備持有申請需說明:

- 第二台設備的業務用途(不得與第一台重複)
- 預計持有期間
- 申請人部門主管簽名確認

盤點中發現無申請紀錄之多設備持有者,TO 小隊要求補件或收回設備。

## §3 汰換制度

### §3.1 正常汰換年限

| 設備類型 | 建議使用年限 | 強制汰換觸發 |
|---|---|---|
| Mac 系列筆電 | 4–5 年 | 滿 5 年,或符合 §3.2 異常汰換條件 |
| PC 筆電(商用等級) | 3–4 年 | 滿 4 年,或符合 §3.2 異常汰換條件 |
| PC 桌機(一般文書) | 4–5 年 | 滿 5 年,或符合 §3.2 異常汰換條件 |
| 高規格工作站(組裝機) | 4–5 年 | 滿 5 年,或顯示卡世代落後 2 代以上 |
| 特規設備(NAS、出貨主機) | 依功能評估 | 功能不足以支撐業務需求時 |

**年限起算日**為設備初次配發使用之日。汰換不代表報廢;降轉備用機或報廢依 §6.4 處理。

### §3.2 異常汰換條件

下列任一條件成立,即可申請異常汰換:

- 硬體故障累計維修費用超過設備現值 50%
- 電池續航低於原廠標稱值 50% 且不堪更換
- 無法安裝當年度業務核心軟體(NetSuite ERP、Google Workspace、作業系統安全更新)
- 因規格不足造成可驗證的工作效率損失(由 IT 小隊確認)

異常汰換申請填寫《電腦設備申請單》(勾選「在職換機」),經部門主管與 IT 小隊審核。

## §4 設備規格標準

### §4.1 業務使用場景基準

WitsPer 日常業務涉及多平台後台同時操作、大量 Google Workspace 頁面、多份 Excel / Sheets 開啟、NetSuite ERP 系統登入及 Power BI 報表。各規格等級以能流暢支撐上述場景為最低合格門檻。

### §4.2 一般規格(全公司一般文書與業務作業)

| 規格項目 | 最低標準 | 建議配置 |
|---|---|---|
| 處理器 | Intel Core i5 第12代 / AMD Ryzen 5 5000 以上 | Intel Core i7 / AMD Ryzen 7 同世代 |
| 記憶體 | 16 GB DDR4/DDR5 | 16 GB DDR5 |
| 儲存裝置 | 256 GB NVMe SSD | 512 GB NVMe SSD |
| 顯示器(筆電) | 14–16 吋 FHD (1920×1080) | 14–16 吋 FHD+ |
| 作業系統 | Windows 11 Pro(PC)/ macOS 最新版支援機型(Mac) | 同左 |
| 連接埠 | USB-A × 2 + USB-C/Thunderbolt × 1 以上 | USB-C/Thunderbolt × 2 以上 |
| 市場參考價(PC 筆電) | NT$20,000–30,000 | NT$25,000–35,000 |
| 市場參考價(Mac 筆電) | NT$32,000–40,000 | NT$35,000–45,000 |

### §4.3 高規格(VU 小隊 / IT 小隊 及有特殊需求之夥伴)

| 規格項目 | 最低標準 | 建議配置 |
|---|---|---|
| 處理器 | Intel Core i7 第12代 / Apple M1 Pro 以上 | Intel Core i9 / Apple M2 Pro / AMD Ryzen 9 |
| 記憶體 | 32 GB | 32–64 GB |
| 儲存裝置 | 512 GB NVMe SSD | 1 TB NVMe SSD |
| 獨立顯示卡(桌機) | NVIDIA RTX 3060 / AMD RX 6600 以上(VU 小隊必備) | RTX 3070 / RX 6700 XT 以上(VU 小隊算圖) |
| 顯示器(桌機) | 27 吋 QHD 以上(VU 小隊) | 32 吋 4K(VU 小隊剪輯) |
| 作業系統 | Windows 11 Pro(PC)/ macOS 最新版(Mac) | 同左 |
| 市場參考價(PC 筆電) | NT$40,000–55,000 | NT$50,000–70,000 |
| 市場參考價(Mac 筆電) | NT$52,000–75,000 | NT$65,000–90,000 |
| 市場參考價(高規桌機) | NT$40,000–60,000 | NT$55,000–80,000 |

高規格設備採購前,IT 小隊主管核准。

### §4.4 標準採購清單(半年檢視一次)

為控管 IT 小隊維護成本與採購效率,TO 小隊維護**《標準採購清單》**,列出當期預設採購之型號(一般 / 高規各 1-2 款 + 標配周邊)。具體型號、廠商與價格由 TO 小隊單獨維護,不列於本原則內文。

清單之設計、檢視與變更規範如下:

| 項目 | 規定 |
|---|---|
| 設計原則 | (1) 規格 ≥ §4.2 / §4.3 最低標準;(2) 可長期供應(不選即將停產 / 支援期將結束);(3) 控管維護成本(同等級集中 1-2 款) |
| 檢視週期 | 每半年一次 |
| 提早檢視觸發條件 | 主力型號停產 / 供應商重大異動 / §4.2 或 §4.3 規格基準變動 |
| 變更核准 | TO 小隊主管;需 IT 規格意見時 TO 小隊主動諮詢 |
| 偏離清單之採購核准 | IT 小隊主管核准(對應 §1.2 雙路徑簽核) |

## §5 配置與換機流程

### §5.1 新進夥伴設備配置

TO 小隊確認錄取後,於報到日前 **5 個工作天**啟動下列三方確認:

1. **部門主管**:填寫《電腦設備申請單》(勾選「新進夥伴報到」)交 TO 小隊
2. **TO 小隊**:確認備用機庫存,判斷可直接配發或需採購;如需採購,啟動 §1.2 採購簽核流程
3. **IT 小隊**:確認系統配置要求(系統版本、軟體授權、VPN 設定等)

三方確認後,TO 小隊填寫設備配發單,於報到當天完成設備交接與簽收。

備用機庫存不足或需採購者,配發時程另行通知,**優先提供臨時備用機銜接報到日**。

### §5.2 在職夥伴換機

在職夥伴提出換機需求時,依序:

1. 夥伴填寫《電腦設備申請單》(勾選「在職換機」),選填申請原因(異常故障 / 規格不足 / 達汰換年限,擇一)並說明
2. 部門主管審核並簽名,確認換機原因合理
3. IT 小隊評估現有設備狀況,確認換機必要性:
   - **達年限**:直接確認,無須額外說明
   - **異常故障**:提供故障紀錄或維修紀錄
   - **規格不足**:說明受影響之具體工作任務(例:NetSuite 跑報表卡頓、Power BI 無法開啟)
4. 兩方確認後,交 TO 小隊安排設備調撥或採購
5. 換機完成後,舊設備交回 TO 小隊,IT 小隊執行資料清除,判斷轉備用機或報廢

**審核週期**:一般情況 3 個工作天內完成評估;緊急情況(設備損毀無法使用)當天完成評估並提供臨時備用機。

## §6 盤點與收納

### §6.1 定期盤點頻率

| 盤點類型 | 頻率 | 負責 | 產出 |
|---|---|---|---|
| 全盤(使用中 + 庫存 + 損壞) | 每半年一次(1 月、7 月) | TO 小隊主導 | 設備全盤清冊 |
| 庫存抽查 | 每季一次 | TO 小隊 | 庫存現況表 |
| 汰換年限提醒掃描 | 每年一次(12 月) | TO 小隊 + IT 小隊 | 汰換候選清單 |

### §6.2 盤點記錄必填欄位

- 資產編號(Tag)
- 設備名稱及型號
- 目前使用人(職名)及部門
- 設備狀態(使用中 / 備用 / 維修中 / 待報廢)
- 初次配發日期
- 最近一次異動日期及異動原因

### §6.3 收納控管

- 備用機統一存放於 TO 小隊指定儲藏空間,不散放於各部門
- 備用機存放時完成出廠設定還原(或保留乾淨備份),確保可立即配發使用
- 損毀設備加貼「待維修」或「待報廢」標籤後集中存放,不與可用設備混置
- 所有設備配發及收回均簽署設備交接單,紙本或數位簽名均可

### §6.4 設備收回程序

夥伴離職或部門調動時:

1. TO 小隊收到離職 / 調動通知後,啟動設備收回
2. IT 小隊執行資料備份及清除(離職者)或帳號切換(調動者)
3. TO 小隊與夥伴完成設備交接,確認設備外觀及功能
4. 更新盤點清冊,設備轉為備用機或啟動報廢流程

設備未依程序收回者,TO 小隊在離職手續完成前提出示警,離職手續方完成。
